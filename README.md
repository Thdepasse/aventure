# 🌏 Aventure Asie

Planificateur de voyage interactif — 40 jours en Asie du Sud-Est.

## Utilisation

Ouvrir `index.html` directement dans un navigateur. Aucun serveur requis.

## Fonctionnalités

- **Timeline interactive** — toutes les étapes dans l'ordre avec détails au clic
- **Vue grille** — aperçu visuel de toutes les destinations
- **Budget détaillé** — tous les postes de dépense, modifiables en direct
- **Toggle saison** — affiche les conditions météo et conseils pour 3 périodes de voyage
- **Ajout d'étapes** — formulaire pour créer ou modifier n'importe quelle étape
- **Photos** — ajouter des images à chaque étape (stockées en base64)
- **Notes** — zone de notes libre par étape
- **Sync GitHub** — sauvegarde automatique des données sur ce repo
- **Export JSON** — téléchargement des données

## Itinéraire

1. Kuala Lumpur (2j) → Manille (1j) → Cebu + Moalboal (4j)
2. Bohol (3j) → Puerto Princesa (2j) → El Nido (4j)
3. Croisière El Nido → Coron (3j) → Coron (3j)
4. Ubud/Bali (4j) → Canggu (3j) → Nusa Penida (3j)
5. Singapour (2j) → Penang (3j) → KL retour (1j)
